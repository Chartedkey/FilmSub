# FilmSub

Художественный перевод английских субтитров на русский с помощью языковых моделей (DeepSeek, OpenRouter).
Сделано для просмотра фильмов на медиаплеере Dune: перевод сохраняется рядом с фильмом как `Фильм.ru.srt`.

## Скачать

Готовый `FilmSub.exe` — в разделе [Releases](../../releases/latest). Установка не нужна.

## Возможности

- Вход: `.srt` или `.mkv` (английская текстовая дорожка извлекается автоматически).
- Предварительный разбор фильма: персонажи, их пол, обращения на «ты»/«вы», термины.
- Два стиля промпта — проверенный и новый (идиомы, сленг, словарь) — и режим их сравнения.
- Встроенный словарь (~2400 выражений: сленг, диалекты, идиомы, жаргон, реалии) с учётом форм слов,
  страны и эпохи фильма, плюс личный словарь с ручной правкой.
- Проверка готового перевода другой моделью через OpenRouter: список ошибок с исправлениями, принятые правки сохраняются отдельным вариантом.
- Экспериментально: пол говорящего по высоте голоса.
- Автообновление из релизов GitHub (без вспомогательных скриптов).
- Синхронизация субтитров со звуковой дорожкой файла, DVD (`VIDEO_TS`) или Blu-ray (`BDMV`) — alass, без нейросетей.
- Остановка и продолжение перевода с того же места.

Подробная инструкция — в [README.txt](README.txt).

## Сборка

Каждое изменение в `main` собирается на GitHub Actions; если номер версии в `filmsub/__init__.py` новый,
публикуется релиз с `FilmSub.exe`. Загрузчик PyInstaller собирается из исходников, в exe вшиты сведения о версии.
Локально: `build_exe.bat` на Windows.

## Синхронизация с DVD / Blu-ray

Добавьте английский SRT для перевода или выберите готовый русский SRT для синхронизации.
Через кнопку выбора фильма можно указать отдельный файл либо папку `VIDEO_TS`, `BDMV`
или корень диска. Папка диска рядом с SRT находится автоматически; одноимённый видеофайл
сохраняет приоритет. Внутренние клипы диска не добавляются как отдельные задания перевода.

Для DVD выбирается самый большой набор `VTS_nn_1.VOB`, `VTS_nn_2.VOB`, … без меню;
язык дорожек берётся из соответствующего IFO, если он доступен. Для Blu-ray выбирается
самый длинный корректный MPLS: учитываются порядок клипов, повторения и точки входа/выхода.
Выбор основного фильма выводится в журнал. На дисках с несколькими фильмами, сложной
DVD-навигацией или ложными Blu-ray-плейлистами автоматический выбор может не соответствовать
нужной версии фильма; для таких изданий используйте отдельно подготовленный видеофайл.
Поддерживаются незашифрованные копии дисков. Извлечение субтитров из дисковых меню не добавлено.
Перед синхронизацией программа показывает список звуковых дорожек: выберите оригинальную
речь на нужном языке (например, французскую для французского фильма). Английская дорожка
не обязательна. Отмена выбора оставляет субтитры без изменений. В списке видны номер,
язык и название дорожки, если они указаны в файле или метаданных диска. Для Blu-ray языки
дополнительно читаются из CLPI; выбор сохраняется между клипами по PID дорожки.
Если языковые метки отсутствуют, дорожки доступны по номеру.

Текст перевода сохраняется; при изменении таймингов создаётся резервная копия SRT.

Проверка: `python -m unittest discover -s tests -v`. Интеграционные проверки звука
используют `ffmpeg` и `ffprobe` из PATH, остальные тесты не требуют внешних программ.
