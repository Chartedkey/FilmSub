# FilmSub

Художественный перевод английских субтитров на русский с помощью языковых моделей (DeepSeek, OpenRouter).
Сделано для просмотра фильмов на медиаплеере Dune: перевод сохраняется рядом с фильмом как `Фильм.ru.srt`.

## Скачать

Готовый `FilmSub.exe` — в разделе [Releases](../../releases/latest). Установка не нужна.

## Возможности

- Вход: `.srt` или `.mkv` (английская текстовая дорожка извлекается автоматически).
- Предварительный разбор фильма: персонажи, их пол, обращения на «ты»/«вы», термины.
- Два стиля промпта — проверенный и новый (идиомы, сленг, словарь) — и режим их сравнения.
- Встроенный словарь (~2400 выражений: сленг, диалекты, идиомы, жаргон, реалии) с учётом форм слов,
  страны и эпохи фильма, плюс личный словарь с ручной правкой.
- Определение пола говорящего по высоте голоса (для рода в русском переводе).
- Автообновление из релизов GitHub (без вспомогательных скриптов).
- Синхронизация субтитров со звуковой дорожкой (alass, без нейросетей).
- Остановка и продолжение перевода с того же места.

Подробная инструкция — в [README.txt](README.txt).

## Сборка

Каждое изменение в `main` собирается на GitHub Actions; если номер версии в `filmsub/__init__.py` новый,
публикуется релиз с `FilmSub.exe`. Загрузчик PyInstaller собирается из исходников, в exe вшиты сведения о версии.
Локально: `build_exe.bat` на Windows.
